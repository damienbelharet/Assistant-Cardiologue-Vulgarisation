💳 Le bip magique

Tu poses ta carte, ça fait « bip », c'est payé. En vrai, c'est une vraie petite communication radio en 4 étapes. Cette fois, c'est toi la carte : à toi d'établir la liaison, de capter l'énergie, d'envoyer ton code, et de le faire valider.

1 Approcher
2 Accorder
3 Moduler
4 Décoder

1Établis la liaison radio

La carte et le terminal se parlent par une onde radio. Mais il y a toujours du bruit autour (parasites des autres appareils). Pour que le message passe, le signal reçu doit rester plus fort que le bruit. Rapproche la carte et trouve jusqu'où la liaison tient :

Trop loin : le signal se noie dans le bruit.

💡 Cet écart entre signal et bruit, c'est le rapport signal sur bruit. Et si la portée est aussi courte, c'est exprès : personne ne peut capter ta carte à distance, par exemple dans le métro.

2Accorde-toi sur la porteuse

Ta carte n'a pas de pile 🔋🚫 ! Elle se nourrit de l'onde du terminal, appelée la porteuse. Mais elle ne capte un maximum d'énergie que si le terminal émet sur la bonne fréquence : c'est l'accord. Règle la fréquence pour faire monter l'énergie au maximum :

Pas accordé : la carte ne reçoit presque rien.

💡 La vraie fréquence du paiement sans contact est 13,56 MHz. Carte et terminal sont réglés pile sur cette valeur pour se comprendre, comme deux radios sur la même station.

3Envoie ton code en le modulant

Réveillée, la carte doit répondre. Pour envoyer un message sans fil, tu modifies l'onde : une onde haute = un 1, une onde basse = un 0. Ça s'appelle la modulation. Voici ton code secret en binaire : envoie-le bit par bit !

Regarde la case qui clignote et clique le bon bouton.

💡 Tout passe ainsi, en binaire, façon morse. Et comme ce code change à chaque paiement, un code intercepté ne sert plus à rien la fois suivante.

4Le terminal décode et vérifie

Le terminal reçoit ta séquence et la décode. Pour repérer les erreurs, tu as ajouté un bit de contrôle (en pointillé) : il vaut 1 si le nombre de 1 est impair, 0 s'il est pair. Le terminal recompte. Mais le bruit a abîmé un bit en route… Lance la vérification :
